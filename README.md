# IBM Full-Stack JavaScript Learning Journey

This repository contains the major hands-on projects completed while pursuing the IBM Full-Stack JavaScript Developer Professional Certificate by Coursera.

## Projects

### 🌱 Paradise Nursery Shopping Application

A modern React-based e-commerce application for browsing and purchasing plants online.

#### Features
- Browse plants by category
- Shopping cart functionality
- Increase/decrease item quantities
- Dynamic cart calculations
- Responsive user interface
- State management using Redux Toolkit

#### Tech Stack
- React.js
- JavaScript
- Redux Toolkit
- React Router
- Vite

---

### 📚 Express Book Reviews API

A RESTful backend application built with Node.js and Express that allows users to browse books and manage reviews.

#### Features
- User registration and authentication
- JWT and session-based authorization
- Search books by ISBN, title, and author
- Add, update, and delete reviews
- Async/Await implementation
- REST API architecture

#### Tech Stack
- Node.js
- Express.js
- JavaScript
- JWT
- Express Session
